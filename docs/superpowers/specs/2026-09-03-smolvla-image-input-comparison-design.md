# SmolVLA 训练与真机图像输入对比设计

## 目标

将 `data/pick_two_tube` 的训练图像与
`eval_obs_20260901_011323` 的真机部署观测放在同一张图中，直观检查双相机的
构图、曝光和颜色分布差异。过程仅离线读取数据，不启动机器人服务。

## 数据与采样

- 训练数据：episodes 25–27，从完整时间序列均匀抽取代表帧。
- 真机数据：按保存 step 排序，从 13 个观测中均匀抽取代表帧。
- camera0 与 camera1 分开成行，并在标题中明确来源和相机编号。
- 图像按 RGB 原值展示，不应用训练增强、归一化或自动亮度修正。

## 输出

生成单个 PNG：
`outputs/smolvla_online_diagnosis/eval_obs_20260901_011323/image_input_comparison.png`。

上半部分为四行采样网格：训练 camera0、训练 camera1、真机 camera0、真机
camera1。下半部分为训练和真机两组数据的 RGB 通道及亮度直方图。每组使用一致
的像素范围和坐标轴，便于直接比较。

## 验证

检查输出文件可读取、尺寸非零，并人工查看相机行标签、颜色顺序和图像内容。
不修改源 parquet、真机观测或部署配置。
